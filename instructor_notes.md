# Instructor notes

## Overview

This lab is an add-on to an existing RSOT for K8s lab. Typically you'll only want it if the client has specifically requested to learn automation.

It can also be used as a demo from your own RSOT for K8s lab environment.

## Instructions

1. Read and understand the goal of the lab. Warning: it is exceedingly simple.
1. Practice the lab once so you can help troubleshoot if a paticipant has a problem.
1. Send an email to the participants in advance of the class telling them about the custom lab. Include a link to either this repo, or your own fork of it.
1. In the email ask them to create their own fork. That way, they'll be able to make changes to the REC and REDB and see the effect.
1. Append or insert a discussion of K8s automation / Argo CD. A G-slides deck is included in the PS folder. The same content is in this repo as a pdf.
1. README.md has step by step instructions to install Argo CD in the lab. There is no need to create a special lab environment, use the same ones from class.
1. Have them do the lab.
